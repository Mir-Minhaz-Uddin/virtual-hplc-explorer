# Virtual HPLC Explorer

An interactive 3D learning experience that helps students explore the main components of a high-performance liquid chromatography system and connect instrument operation with chromatographic separation.

## Features

- Rotatable 3D HPLC model with detailed component views
- Guided lessons covering injection, separation, and UV detection
- Synchronized compound bands and chromatogram peaks
- Flow-rate, mobile-phase, and efficiency experiments
- Interactive glossary, quizzes, and troubleshooting exercises

## Educational scope

This independent educational simulation uses hypothetical compounds and simplified scientific models. It is not affiliated with or endorsed by any instrument manufacturer, and it is not intended for instrument operation, method validation, or prediction of real analytical results.
